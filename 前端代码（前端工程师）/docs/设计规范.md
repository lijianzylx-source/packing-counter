# 设计规范（Design System）

> 来源：Stitch 产出的 `industrial_logistics_utility/DESIGN.md`，已整理为可执行的分层规范。
> 落地方式：**令牌在 CSS 变量**（`assets/css/tokens.css`），工具类与组件样式都直接引用同一套变量（`assets/css/utilities.css`、`assets/css/components.css`）——改一个值，全站生效。

---

## 1. 风格定位

**Modern Industrial Pragmatism（现代工业实用主义）**：为跨境物流仓储的高频重复作业设计。

| 原则 | 落地要求 |
|------|---------|
| 瞬时可读 | 数字类信息（件数、金额）要在手臂距离、仓库照明下看得清 → 等宽字体 + 高对比度 |
| 内联非打断 | 告警、编辑一律就地展开，**禁止模态框与弹窗**（除确认删除外） |
| 物理触控 | 可点区域 ≥44px，主要操作 ≥56px |
| 结构优先 | 用 1px 描边与背景色差分层，而非层层阴影 |

---

## 2. 颜色

### 2.1 色板（`tokens.css` 中的 CSS 变量）

| 语义 | 变量 | 色值 | 用途 |
|------|------|------|------|
| 主蓝 | `--c-primary` | `#00288E` | 主按钮、强调 |
| 作业蓝 | `--c-primary-container` | `#1E40AF` | 提交、选中、图表主色 |
| 辅助蓝 | `--c-secondary` | `#0051D5` | 链接、次级强调 |
| 结算琥珀 | `--c-income` / `--c-income-deep` | `#F59E0B` / `#B45309` | **金额专用**，不与状态色混用 |
| 成功 | `--c-success` | `#10B981` | 已连接、已完成 |
| 警告 | `--c-warning` | `#F59E0B` | 离线、异常提示 |
| 错误 | `--c-error` / `--c-error-deep` | `#EF4444` / `#991B1B` | 校验失败、删除 |
| 页面底 | `--c-surface-bg` | `#F8FAFC` | 页面背景 |
| 卡片面 | `--c-surface-card` | `#FFFFFF` | 卡片、输入框 |
| 次级面 | `--c-surface-elevated` | `#F1F5F9` | 表头、浅底块 |
| 描边 | `--c-border-subtle` / `--c-border-strong` | `#E2E8F0` / `#CBD5E1` | 分隔线 / 输入框 |
| 文字 | `--c-text-display` / `--c-text-body` / `--c-text-muted` | `#0F172A` / `#334155` / `#64748B` | 标题 / 正文 / 次要 |

### 2.2 规则

- **金额永远用琥珀色**，状态永远用语义色，两者不得混用。
- 状态**不得只靠颜色表达**，必须同时有文字或图标。
- 正文对比度 ≥ 4.5:1；数据读数 ≥ 7:1。
- 图表单序列只用主蓝 `#2563EB`（图表专用 `--c-chart`），**不放图例**（标题已说明画的是什么）。

## 3. 字体

| 用途 | 字体 | 令牌 |
|------|------|------|
| 数字 / 金额 / 日期 | JetBrains Mono | `--font-mono` |
| 标题 / 分区名 | Space Grotesk | `--font-head` |
| 正文 / 控件 | Inter | `--font-body` |

数字一律等宽，避免连加时数字跳动；表格与坐标轴数字使用 `font-variant-numeric: tabular-nums`。

字阶见 `tokens.css` 的 `--text-*` 变量（display-income / headline-lg / body-md / label-ui 等）。

---

## 4. 间距与圆角

- 间距刻度：`4 / 8 / 12 / 20 / 32 px`（`--space-xs … --space-xl`）。
- 圆角：卡片 4px、输入框/按钮 6px、徽章 8px、状态点全圆。
- 页面留白：移动端 16px，桌面端 24px。

---

## 5. 组件约定

| 组件 | 类名 | 规范 |
|------|------|------|
| 卡片 | `.c-card` / `.c-card--strong` / `.c-card--pad` | 1px 描边 + 极浅阴影 |
| 按钮 | `.c-btn` + `--primary/--secondary/--ghost/--danger` | 高 ≥44px（`--lg` 56px），按下 1px 下沉 |
| 快捷加件 | `.c-step` | 高 48px，等宽数字，1.5px 描边 |
| 输入框 | `.c-input` / `.c-input--lg` | 聚焦变主蓝 + 3px 柔光环，无模糊光晕 |
| 徽章 | `.c-badge` + `--primary/--success/--warning/--error/--income` | 11–12px 标签字 |
| 状态点 | `.c-dot` + `--ok/--warn/--err` | 8px 圆点，**必须配文字** |
| 提示条 | `.c-alert` | 内联框，不用弹窗；错误用红框 + 浅红底 |
| 数据表 | `.c-table` | 表头浅底，行分隔 1px，数值右对齐等宽 |
| 行内操作 | `.c-row-btn` | 32px 高，紧凑排布在行内 |
| 开关 | `.c-switch` | 44×26 |

---

## 6. 布局

- **桌面（≥1024px）**：左侧 252px 固定导航（品牌 / 导航 / 今日概览 / 账号），右侧顶栏 + 内容区（最大 1240px 居中）；记录页为「左录入 + 右概览」双栏。
- **移动（<1024px）**：同一份 DOM，侧边栏折叠为底部导航，内容单列。
- 触控目标不小于 44px，主操作 56px。

---

## 7. 图表（dataviz 规范）

- 单序列 → 主蓝一色、**不放图例**；标题说明画的是什么。
- 柱宽 ≤24px、顶端 4px 圆角、底部方角；网格线 1px 实线、克制。
- **只标注极值**（最大值），其余数值交给 Y 轴、悬停提示与表格视图。
- **未记录的日期不画柱**（避免把「没记录」误读成 0 件）。
- 每张图必须有**表格视图**（颜色之外的等价读数通道）与悬停提示。

---

## 8. 命名与分层

- 组件类名：`c-<block>__<element>`（如 `.c-kpi__value`）；布局类名：`l-<block>`；工具类名：`u-<property>`。
- 文件分层：`tokens`（令牌）→ `base`（重置/排版）→ `components`（组件）→ `layout`（骨架）→ `chart`（图表）。
- JS 分层：`config`（配置）→ `core`（纯逻辑，可单测）→ `store`（持久化）→ `api`（接口）→ `auth`（会话）→ `ui`（外壳与通用交互）→ `chart`（图表）→ `pages/*`（页面逻辑）。
