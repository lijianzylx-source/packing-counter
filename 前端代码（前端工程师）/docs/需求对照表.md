| 需求 | 落地位置 | 说明 |
|------|---------|------|

| F-007 日均与最高单日 | `dashboard.html` 效能明细 + 最高单日卡 | — |
| F-008 按月切换统计 | `dashboard.html` / `history.html` | 月份切换器 |
| F-009 历史列表 | `history.html` 账本表格 | 日期/件数/单价/小计/备注 |

## Stitch 原稿的问题清单（本次已修复）

| # | 问题 | 修复 |
|---|------|------|
| 1 | 四个页面互不相通，导航是 `#today-input` 等**不存在的锚点** | 统一外壳 `ui.js` 渲染真实路由，五个页面互相跳转 |
| 2 | 每个页面内联一份 3KB 的 Tailwind 令牌配置 | 令牌统一收进 `assets/css/tokens.css`（CSS 变量），Tailwind CDN 整体移除 |
| 3 | 数据全部写死（4,320 件 / ¥6,480.00 / 工号 PK-9042） | 全部接真实数据层（`core.js` + `store.js`） |
| 4 | 「保存」只是闪一下边框，没有落盘 | `store.upsertRecord` 真实写入 localStorage |
| 5 | 登录是 `setTimeout` + `alert` 假流程 | 接真实接口 `/api/register|login`，错误内联红框 |
| 6 | 固定展示「401 鉴权失败」演示框 | 改为按需显示真实错误 |
| 7 | 补录表单缺「不可选未来日期」的校验 | 提交前校验 + `max` 限制 |
| 8 | 缺「系统设置」页，PRD 的单价/提醒/导出无处安放 | 新建 `pages/settings.html` |
| 9 | 图表用 div 手搓、图例三项、虚线基准线、脉冲动画 | 换成 dataviz 规范单序列 SVG 图表 + 表格视图 |
| 10 | 假硬件信息（电子秤 COM1、扫码枪 USB-HID、RS232 设备链） | 替换为真实的存储 / 服务器状态 |
| 11 | 内联脚本与 HTML 混写，每个页面一份 | 逻辑拆到 `assets/js/pages/*.js`，分层清晰 |
| 12 | 无测试 | `test/core.test.js` 覆盖 PRD §5 全部业务规则（18 项） |
| 13 | 依赖 Tailwind CDN 与 Google Fonts 图标字体，**外网不可达时白屏** | 移除两处 CDN：工具类本地化（`utilities.css`）、图标改为内联 SVG 精灵（`icons.js`） |
| 14 | 密码「显示/隐藏」切换依赖图标字体 | 改为切换 `<use href>` 指向，并同步 `aria-label` |
| 15 | 顶栏标题与导航高亮写死在 HTML 里 | 由 `ui.js` 依据路由表统一渲染，当前页 `aria-current="page"` |
