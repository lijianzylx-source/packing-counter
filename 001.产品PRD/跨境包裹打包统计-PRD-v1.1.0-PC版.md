## 0. 这一版做了什么

| 变更 | 说明 |
|------|------|
| 新增 PC-001 ~ PC-010 | PC 版布局与效率需求（导航、仪表盘、历史表格、快捷键等） |
| 功能范围 | **不新增业务功能**。记录、统计、历史、导出、账号的全部能力与 v1.0.1 完全一致，只是「在电脑上看」的方式不同 |
| 实现方式 | 与移动版**同一套代码、同一套账号、同一份数据、同一个网址**；按视口宽度自动切换布局，不做「PC / 移动」两套应用 |
| 断点 | 视口宽度 ≥ 1024px 启用 PC 布局；< 1024px 沿用移动版布局 |

> **为什么不做成独立应用**：两套代码意味着以后改一个业务规则要改两遍、容易漏；账号与数据也在同一个服务端，一套代码才能保证「手机上记的，电脑上看得见（同一浏览器）」与「多设备同步」这类后续需求只做一次。

## 1. 背景与目标

### 1.1 背景
v1.0.1 的界面是「手机优先」：底部标签栏、单列卡片、列表式历史。放到电脑上有三个问题：

1. **空间浪费**——1280px 宽的屏幕只用了中间一条窄列，左右大片留白；
2. **来回切换**——想同时看「今天的量」和「本月趋势」必须切页；
3. **效率低**——补录/改记录要点开卡片再点按钮，一行一条的操作链路长。

### 1.2 目标
| 目标 | 衡量方式 |
|------|---------|
| 桌面端信息密度合理 | 1280px 下主内容区宽 1240px，仪表盘左右分栏，历史为表格形态 |
| 一屏看到关键数据 | 侧边栏常驻「今日概览」，任意页面都能看到今日/本月四个数 |
| 少点几下 | 键盘快捷键覆盖「聚焦输入 / 保存 / 切页」 |
| 不破坏移动端 | < 1024px 的表现与 v1.0.1 完全一致（同一个页面、同一套逻辑） |

## 3. 功能需求（PC 版）

| 需求编号 | 用户故事 | 验收标准 |
|---------|---------|---------|
| PC-001 | 作为电脑用户，我希望左侧有常驻导航，切换视图不用去屏幕底部找。 | ≥1024px 时左侧显示 252px 侧边栏，含品牌、四个导航项、今日概览、账号条；当前页高亮；侧边栏随页面滚动固定（sticky）。 |
| PC-002 | 作为电脑用户，我希望任何页面都能看到今天和本月的汇总。 | 侧边栏「今日概览」常驻，显示今日件数、今日收入、本月件数、本月收入；数值与首页卡片实时一致。 |
| PC-003 | 作为电脑用户，我希望在电脑上能一眼看出当前在看哪个页面。 | 顶栏显示视图名（记录 / 历史记录 / 统计 / 设置），浏览器标签页标题同步变化。 |
| PC-004 | 作为电脑用户，我希望录入区和数据区并排显示，不用来回切页。 | 记录页分两栏：左侧为录入表单（固定 460px），右侧为「今日收入」主数字 + 三个统计卡；两栏顶端对齐。 |
| PC-005 | 作为班组长，我希望历史记录是表格形态，便于横向比对与扫读。 | 历史列表在 PC 上为五列（日期 / 件数 / 收入 / 备注 / 操作）定宽对齐，行间为 1px 分隔线，悬停高亮；列宽不随内容抖动。 |
| PC-006 | 作为电脑用户，我希望指标卡排成一行，不要上下堆叠。 | 统计页 8 个指标卡排为 4 列 × 2 行；记录页统计卡 3 列并排。 |
| PC-007 | 作为电脑用户，我希望趋势图更宽更高，能看清每天的差异。 | 图表在 PC 上高度 300px；绘图区宽度上限 900px 并居中，避免柱子被拉散；柱宽仍遵守 ≤24px 上限。 |
| PC-008 | 作为电脑用户，我希望筛选控件不要被拉成一条横幅。 | 历史页的搜索框与日期筛选在 PC 上限宽（搜索 ≤620px、日期 ≤210px/个），并按行紧凑排列。 |
| PC-009 | 作为电脑用户，我希望用键盘快速操作。 | `N` 聚焦件数输入框；`Ctrl/⌘ + Enter` 保存当天记录；`1/2/3/4` 切换记录/历史/统计/设置；输入框内不触发这些快捷键。 |
| PC-010 | 作为电脑用户，我希望点侧边栏账号区能去账号设置。 | 点击侧边栏底部账号条跳转到设置页账号区；显示用户名首字母头像与登录状态。 |

## 4. 业务规则（新增）

13. **布局自适应**：视口 ≥1024px 启用 PC 布局，<1024px 启用移动布局；两者共用同一套数据、账号与业务逻辑，不存在「PC 版数据」与「移动版数据」之分。
14. **视图状态共享**：切换视口宽度不丢失当前视图、月份、图表筛选与行内编辑状态。
15. **快捷键作用域**：单键快捷键（`N`、`1`~`4`）仅在焦点不在输入框/下拉框时生效；`Ctrl/⌘+Enter` 仅在记录页生效。

## 5. 非功能性需求

| 类别 | 需求 |
|------|------|
| 布局 | 1280px 与 1920px 下均无横向滚动条；侧边栏固定宽 252px，主内容最大 1240px 居中。 |
| 性能 | 与移动版一致，切换视图无明显卡顿；图表随窗口尺寸重绘（防抖 150ms）。 |
| 可用性 | 键盘可达：导航项、按钮、表单均为原生可聚焦元素；焦点态可见。 |
| 一致性 | PC 版沿用同一套配色与组件（商务蓝设计变量），不引入新配色。 |
| 响应式 | 1024px 以下自动回退移动布局，无需用户手动切换。 |

## 6. 验收清单（PC 版）

- [ ] 视口 ≥1024px 时出现左侧导航栏，含四个视图入口；<1024px 时底部导航条出现、侧边栏消失。
- [ ] 侧边栏「今日概览」数值与首页统计卡一致。
- [ ] 顶栏显示当前视图名，切换视图时同步变化。
- [ ] 记录页在 PC 上为「左表单 + 右概览」双栏，窄屏回退单栏。
- [ ] 历史页在 PC 上为五列对齐的表格形态，窄屏回退卡片形态。
- [ ] 统计页 8 个指标卡排为 4 列。
- [ ] 趋势图在 PC 上高度 300px，绘图区居中，柱子不散开。
- [ ] 历史页筛选控件在 PC 上不被拉满整行。
- [ ] `N` 聚焦件数输入框；`Ctrl+Enter` 保存；`1`~`4` 切换视图；在输入框内按 `1` 不会切页。
- [ ] 窗口从 1280px 缩到 700px，布局自动切回移动版且当前视图不变。
- [ ] PC 版与移动版共用同一账号：PC 登录后，手机浏览器登录同一账号看到的记录一致（同一浏览器验证）。
