## 1. 产品背景与目标

### 1.1 背景
用户每天需要记录自己打包的跨境包裹数量，目前为手工记录（纸笔或备忘录），无法快速：
- 知道“今天/本月一共打了多少件”；
- 知道“今天/本月收入是多少”；
- 回溯历史数据并与实际结算对账。

v1.0 解决了记录与统计，但**没有账号**：任何打开页面的人看到的是同一份本机数据，无法区分使用者，也不便于在多台设备上识别“这是我的账号”。

### 1.2 核心目标
做一款**极简、轻量、手机优先**的小工具，让用户在 3 步之内完成每日打包数量记录，并自动按 **1.5 元/件** 计算收入；v1.0.1 补上**用户名 + 密码**的注册登录，让记录归属于一个明确的账号身份。

### 1.3 成功指标
| 指标 | 定义 | 目标值 |
|------|------|--------|
| 记录完成时长 | 打开首页 → 保存一条记录所需时间 | ≤ 10 秒 |
| 登录耗时 | 打开页面 → 进入记录页（含自动登录） | ≤ 2 秒 |
| 月度统计准确率 | 自动计算收入与手工核算一致的比例 | ≥ 99% |
| 周活跃率 | 每周至少记录 1 次的用户占比 | ≥ 80% |
| 登录失败可恢复 | 密码错误时给出明确提示且不泄露账号是否存在 | 100% |

## 2. 用户画像

### 2.1 主要用户：打包员 / 仓库操作员
- 每天工作结束后需要快速记录当天打包件数；
- 对收入敏感，希望按件计费结果一目了然；
- 手机操作为主，希望界面大、步骤少、无需学习；
- 可能共用一台设备，需要知道自己登录的是哪个账号。

### 2.2 次要用户：小卖家 / 班组长
- 需要查看多人或多日汇总；
- 需要导出数据用于工资结算或对账（后续版本支持）。

## 3. 核心业务流程

### 3.1 记录流程（与 v1.0 相同）

```text
开始 → 选择日期（默认今天）→ 输入当天打包件数
     → 系统自动计算收入 = 件数 × 1.5 元 → 保存记录
     → 首页/统计页查看当日/当月汇总
```

### 3.2 登录流程（v1.0.1 新增）

```text
打开页面
  │
  ├─ 本地有登录令牌 ──► 向服务器校验 /api/me
  │      ├─ 有效 ─────────► 进入记录页
  │      ├─ 失效(401) ─────► 清除令牌 → 回到登录页
  │      └─ 服务器不可达 ──► 离线模式：进入记录页并提示「未校验」
  │
  └─ 本地无登录令牌 ──► 登录页
         ├─ 登录 ──► 校验通过 → 签发令牌 → 进入记录页
         ├─ 注册 ──► 创建账号并直接签发令牌 → 进入记录页
         └─ 服务器不可达 ──► 可选择「离线使用（不登录）」
```

| 需求编号 | 用户故事 | 验收标准 |
|---------|---------|---------|
| F-001 | 作为打包员，我打开首页就能直接录入今天的数量，不用先选日期。 | **首页日期固定显示当天，不可选择、不可编辑**（只读展示，如「10 月 30 日 星期五」）。 |

| F-013 | 作为用户，我希望有每日提醒，避免忘记记录。 | 可选开启每日提醒（默认 21:00）；提醒文案可自定义。 |

### 4.6 账号注册与登录（v1.0.1 新增）

| 需求编号 | 用户故事 | 验收标准 |
|---------|---------|---------|
| F-014 | 作为新用户，我想用「用户名 + 密码」注册一个账号。 | 注册页含用户名、密码、确认密码三项；密码两次不一致时前端直接报错；注册成功后**自动登录**并进入记录页；注册响应中不包含密码或密码哈希。 |
| F-015 | 作为老用户，我想用用户名和密码登录。 | 登录页只需用户名和密码；登录成功进入记录页；密码错误显示「用户名或密码不正确」，**不区分**“用户不存在”与“密码错误”；服务器不可达时提示可离线使用。 |
| F-016 | 作为用户，我不想每次打开页面都重新登录。 | 登录令牌存于本地；下次打开页面自动向服务器校验（`GET /api/me`），有效则直接进入记录页；令牌失效（401）时清除本地令牌并回到登录页。 |
| F-017 | 作为用户，我想退出登录。 | 设置页「账号」区展示当前用户名与登录状态，并提供「退出登录」按钮；退出需二次确认；退出后服务端令牌立即作废，本地令牌被清除。 |
| F-018 | 作为用户，当服务器临时不可用时，我仍要能记录数据。 | 服务器不可达时进入**离线模式**：提示条说明「未校验」，记录与统计功能全部可用；提供「以离线模式进入（不登录）」入口。 |
| F-019 | 作为用户，我希望能指定服务器地址（换端口、换电脑、手机访问局域网）。 | 登录页提供「服务器地址」输入框；**默认按「当前主机名 + 接口端口」自动推导**（手机打开 `192.168.x.x:5174` → 自动连 `192.168.x.x:5173`，不能写死 localhost，否则手机上永远连不上）；修改后点「连接」立即生效并保存在本机；连接状态实时显示（已连接 / 无法连接 / 被浏览器拦截）。 |
| F-020 | 作为打包员，我不希望误把今天的量记到别的日期上。 | 首页无任何日期选择控件，日期区域为只读文本；历史页的补录与行内编辑才涉及日期，两者互不影响。 |
| F-021 | 作为用户，我想上传一张本地图片作为我的头像。 | 设置页点击头像（或「更换头像」）打开系统文件选择器；仅接受图片、原始文件 ≤ 8MB；自动**居中裁剪为 256×256** 后保存；设置页与侧边栏同步显示；提供「恢复默认头像」。**前端已实现**；后端接口 `POST /api/me/avatar` 未就绪时自动降级为「保存在本机」并提示。 |

## 5. 业务规则

### 5.1 ~ 5.5 记录类规则（沿用 v1.0）

1. **收入计算公式**：`收入 = 打包件数 × 单件收入`，单件收入默认 **1.5 元**。
2. **件数规则**：件数为大于等于 0 的整数；允许为 0，表示当天无产出或请假。
3. **记录唯一性**：每个自然日仅允许存在一条记录；重复保存视为修改。
4. **统计口径**：
   - “今日”指当前自然日 00:00–23:59；
   - “本月”指当前自然月 1 日至当月最后一日；
   - 未记录的日期不计入“工作天数”，但计入“未记录天数”。
5. **单价调整影响**：修改单价后，所有历史记录收入按新单价重新计算。

### 5.6 账号规则（v1.0.1 新增）

6. **用户名规则**：长度 2–20 个字符，仅允许中文、英文、数字、下划线 `_`、短横线 `-`；首尾空格自动去除；**大小写不敏感判重**（`Packer` 与 `packer` 视为同一账号）。
7. **密码规则**：长度 6–72 位；服务端只保存 scrypt 派生值与随机盐，**任何接口都不返回密码或密码哈希**。
8. **令牌规则**：登录/注册成功后签发 32 字节随机令牌；令牌存于服务端会话表（有效期 30 天，过期自动清理），客户端存于本地；请求接口时以 `Authorization: Bearer <token>` 携带。
9. **登录保护**：同一用户名连续 5 次密码错误即锁定 15 分钟；「用户不存在」与「密码错误」返回**相同提示与相同状态码**，防止通过响应差异探测账号是否存在。
10. **账号与本地数据的关系**：**打包记录与设置始终保存在浏览器本地，不上传服务器**。账号只承担身份识别作用；同一浏览器只有一份本机数据，与账号无关；换设备登录不会带走本机数据（本版本不做云端同步）。
11. **服务器地址**：接口基址默认与页面同源；页面以 `file://` 打开时默认 `http://localhost:5173`；用户可在登录页改写并保存到本机。浏览器对「本地文件 → 本机服务」有安全拦截，此时页面提供「在服务器上打开页面」按钮（顶层跳转不受该拦截影响）。
12. **首页日期恒为当天**：记录页的日期为只读展示，永远是本地自然日，不提供选择控件。补录与修改历史记录统一在历史页完成：
    - 「补录这天」：选择日期（不可选未来日期）→ 该日期以行内编辑态出现，填件数与备注后保存；
    - 行内「改」：直接修改该条记录的件数与备注。
    - 两种入口最终都调用同一条写入逻辑（同一天覆盖），与首页保存同源。

## 6. 数据模型

### 6.1 记录表（Record，存在浏览器本地）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| date | string (YYYY-MM-DD) | 记录日期 |
| count | integer | 打包件数，≥ 0 |
| unitPrice | decimal | 单件收入，默认 1.50 |
| income | decimal | 收入，计算字段 = count × unitPrice |
| note | string | 备注，可选，≤ 100 字 |
| createdAt | timestamp | 创建时间 |
| updatedAt | timestamp | 最后修改时间 |

### 6.2 设置表（Settings，存在浏览器本地）

| 字段 | 类型 | 说明 |
|------|------|------|
| unitPrice | decimal | 默认单件收入，默认 1.50 |
| reminderEnabled | boolean | 是否开启每日提醒 |
| reminderTime | time | 提醒时间，默认 21:00 |
| reminderText | string | 提醒文案 |

### 6.3 用户表（User，存在服务器）—— v1.0.1 新增

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 用户唯一标识（`u_` + 16 位十六进制） |
| username | string | 用户名，2–20 位，大小写不敏感唯一 |
| passHash | string | scrypt 派生值，格式 `scrypt$N$r$p$salt$hash` |
| createdAt | timestamp | 注册时间 |
| lastLoginAt | timestamp | 最近一次登录时间 |

### 6.4 会话表（Session，存在服务器）—— v1.0.1 新增

| 字段 | 类型 | 说明 |
|------|------|------|
| token | string | 64 位十六进制随机令牌（主键） |
| userId | string | 关联用户 id |
| createdAt | timestamp | 签发时间，超期 30 天自动清理 |

## 7. 界面与交互概述

### 7.1 登录 / 注册页（v1.0.1 新增）
- 品牌标识 + 一句说明；「登录 / 注册」分段切换。
- 登录态：用户名、密码；注册态：额外显示「确认密码」。
- 主按钮文案随模式切换（登录 / 注册并登录）。
- 底部显示服务器连接状态（绿点＝已连接，黄点＝不可用）；不可用时出现「以离线模式进入（不登录）」。
- 错误信息用红框内嵌展示，不弹窗。

### 7.2 首页（今日记录 + 统计卡片区）
- 顶部卡片：今日件数、今日收入、本月累计件数、本月累计收入。
- 中部输入区：**日期只读展示（固定当天）**、件数输入（大号数字键盘）、实时收入预览。
- 底部操作：保存、查看历史、设置。

### 7.3 历史页
- 默认展示当月列表，按日期倒序。
- 顶部月份切换器；支持滑动/点击切换月份。
- 每条记录可删除；点「改」就地展开行内编辑（件数 + 备注 + 存/取消）。
- 筛选区提供「补录这天」：选日期后以行内编辑态插入该条记录。

### 7.4 统计页
- 当月总览：总件数、总收入、工作天数、日均件数、日均收入。
- 简单趋势图：近 7 天/30 天件数柱状图（单序列，不放图例）。
- 最佳单日高亮。

### 7.5 设置页
- **账号**（置顶）：头像首字母、用户名、登录状态、退出登录按钮、数据归属说明。
- 单件收入设置。
- 每日提醒开关与时间。
- 数据导出 / 备份 / 恢复。
- 关于/帮助（含版本号）。

## 8. 非功能性需求

| 类别 | 需求 |
|------|------|
| 性能 | 首页加载 ≤ 1 秒；保存记录 ≤ 300 ms；登录接口 ≤ 500 ms。 |
| 可用性 | 手机优先；大按钮、大字体；登录/注册各一步表单。 |
| 可靠性 | 记录数据本地持久化；账号数据服务端落盘（JSON 文件），服务重启不丢账号。 |
| 可访问性 | 输入框有明确标签；收入数字使用高对比色；错误信息配图标+文字，不只靠颜色。 |
| 安全 —— 密码 | 仅存 scrypt 哈希 + 随机盐；接口不返回密码/哈希；登录失败提示统一。 |
| 安全 —— 会话 | 令牌为 32 字节随机值，服务端可即时作废；令牌不出现在 URL 中。 |
| 安全 —— 传输 | 响应带 `X-Content-Type-Options`、`X-Frame-Options`、CSP；账号数据目录禁止通过 HTTP 访问。 |
| 隐私 | **打包记录与设置不上传服务器**；账号仅含用户名与密码哈希。 |
| 离线能力 | 记录功能支持离线（本地存储）；登录校验需要服务器，不可用时降级为离线模式。 |
| 部署 | 零依赖 Node 进程即可运行；对外提供服务时需自行套 HTTPS。 |

### 9.1 v1.0.1（本次交付）
- 用户名 + 密码注册、登录、退出登录；
- 令牌会话与自动登录，失效自动回登录页；
- 服务器不可达时的离线降级；
- v1.0 的全部记录、统计、历史、导出、设置功能保持不变。

### 9.2 后续规划
| 版本 | 功能 |
|------|------|
| v1.1 | 多设备云端同步（记录随账号走）、修改密码、找回密码 |
| v1.2 | 多人员/班组长汇总视图、按角色区分单价 |

## 11. 附录：快速验收清单

**v1.0 原有项（保持通过）**
- [ ] 输入 100 件，系统显示收入 150.00 元。
- [ ] 修改单件收入为 2.0 元后，历史记录收入同步更新。
- [ ] 同一天保存两次，后一次覆盖前一次，不产生重复记录。
- [ ] 删除一条记录后，首页当月累计实时减少。
- [ ] 切换到无网络环境，仍可正常录入与查看历史。

**v1.0.1 新增项**
- [ ] 注册新账号后自动登录，直接进入记录页。
- [ ] 注册时两次密码不一致，提示「两次输入的密码不一致」。
- [ ] 用户名重复时提示「该用户名已被注册」。
- [ ] 密码错误与用户不存在显示**同样的**「用户名或密码不正确」。
- [ ] 同一用户名连续 5 次密码错误后被锁定 15 分钟。
- [ ] 刷新页面后仍处于登录态，无需重新输入密码。
- [ ] 令牌失效（退出或被作废）后回到登录页。
- [ ] 设置页「账号」区显示当前用户名；退出登录后回到登录页。
- [ ] 服务器停止后打开页面，可选择离线进入且记录功能可用。
- [ ] 通过 HTTP 无法访问账号数据文件（返回 403）。
- [ ] 接口响应中不出现密码或密码哈希字段。
- [ ] 登录页可修改「服务器地址」，换端口后点「连接」能立即连上。
- [ ] 以 `file://` 打开时，页面提示被浏览器拦截，并提供「在服务器上打开页面」按钮，点击后可正常进入应用。
- [ ] 首页日期为只读文本，显示当天，且不存在任何日期选择控件。
- [ ] 首页保存后，统计与历史同步更新当天的记录。
- [ ] 历史页「补录这天」可为一个没有记录的日期新增记录，不能选未来日期。
- [ ] 历史页行内「改」可修改件数与备注，保存后统计即时刷新。
